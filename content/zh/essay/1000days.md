# 写作演变分析：日志与非日志合观

> 分析对象：`04Journal`、`00写作`（排除 `Review`）、`03灵感`（排除 `得到大脑`）
> 数据截止：2026-10-08；文档生成：2026-09-23
> 状态：**仅存工作区**，未写入 vault。全部结论附判据与可复跑脚本（`writing_evolution/*.py`）。

## 0. 摘要（六条核心发现）

1. **体裁走的是一条"制度化"路径**：文言史官体 → 模板日记 → 新闻通讯体 → 个人复盘模板 → 日程/时间统计台账 → 论证性长文。**文体实验的对象从"别人怎么写"变成"我怎么记"，最后变成"我自己怎么被统计"。**
2. **目的从"留痕"转向"生产"**：2022–2023 是"建一个我能掌控的世界"（B Project / #75 / 巨型问题清单）；2024 是"对别人说话"（博客 + 新闻周报）；2025 是"管理自己"（复盘模板）；2026 是"产出可引用物"（学术大纲、翻译校订、系列小说）。
3. **两条轨道在 2025 年 11 月才对上**：`04Journal → 写作/灵感` 的引用共 **169 条**，其中 **2025-11 才出现第一条**（周报-31），随后 126 条来自周记。此前四年，日志和写作在文件层面互不相干。
4. **耦合方向是单向的，周记是"作品索引表"**：169 条引用里 126 条出自周记的「读/写/观/玩」四节；反向（作品 → 日志）只有 **5 条**。**日志索引作品，作品不回链日志。**
5. **2026 年日志与正式写作是替代关系，不是上下游**：日记天数与非日志字数呈明显反相关——1–3 月日记 71 天 / 非日志 2,088 字；6 月日记 7 天 / 非日志 22,474 字。
6. **兑现率是 2026 年最实质的变化**：全库 455 个写作/灵感文件中 **79 个是 <30 字的空壳**，但 **2026 年空壳为 0**；2025 年 86 篇日记里 73 篇是空模板，2026 年 163 篇日记 100% 有内容。

## 3. 五阶段：体裁 / 目的 / 连续性

### 阶段一 · 2022.05–2023.07（高一下–高二）
- **体裁**：文言史官体课堂速写（`# 生物——刘秋菊`，以「某」自称，用「曰/遂/其」叙事）；模板日记（`日出收集箱 / 事件 / 想法与感受`）；世界观工程文档（`B Project` 2022-10-15、《B Project：我是谁？》2023-01-04、《乌托邦计划#75》2022-12-14、`#75-3.1/3.2` 2023-01）。
- **目的**：留痕 + 自娱 + 给幻想世界建档。同期的《理想主义者》是一份 5.5 万字的立誓清单（阅读、哲学问题、自我改造）。
- **连续性**：每年仅 3 篇日志，写作是**不定期爆发**（2022-11-12 单日 54,989 字；2023-01-04 单日 6,813 字）。`#75` 是唯一跨阶段的资产。

### 阶段二 · 2023.09–2024.06（高三）
- 日志 3 篇，写作几近为零，仅存《影子报告改编的大纲吗》（2023-06）与《目录系统》（笔记体系的方法论长思）。
- **特征**：**叙述退位、方法论上位**。不是停笔，是笔锋转向"我该怎么组织我写的东西"。

### 阶段三 · 2024.07–2025.01（高考后–大一上）
- **四条新体裁同时开张**：① 月度时间线日志（6 个月，2,355→863 字递减）；② 新闻通讯体周报（周报-1～9，`国际新闻/军事/经济/社会/外交/公共卫生/人文`，最长 5,281 字）；③ 自省散文（《聊天耗费精力，但》07-25、《只有自动写作能让我说出真话》07-28、《后发的构建》12-07）；④ 第一篇小说《天桥》（2024-08-14，9,943 字）。
- **目的**：转为**对外说话**——建站（`为什么要写博客` 2024-08-05、Hexo/Hugo 笔记）、做新闻中介（周报自述"『本周』指我在媒体上看见的，而非本周发生的"）。
- **连续性**：周报制度当年即衰减（周报-10 混入 `Limbus Company / 阅读 / 流行梗 / 想法`；周报-11～13 退化为 `做了什么/没做什么`）。

### 阶段四 · 2025.02–2026.01（大一下–大二上）
- **体裁**：周报定型为个人复盘（周报-31 起固定为 `本周回顾 / 读 / 写 / 见 / 玩 / 观 / 食 / 行 / 责 / 下周目标`）；日记按天建档但**大量留空**（73/86）；`To Do List` 出现。
- **目的**：**自我管理**取代自我表达。素材从外部世界退回到校园、课程与游戏（《趣智校园能被赶出校园吗？》含 2025-09-19 征信数据；跑团记录；暗黑地牢同人；中篇大纲群：苍白契约、染色、影子报告、杀死理念）。
- **连续性**：**制度建成、执行未跟上**的一年，全库兑现率最低点。周报缺号 25–28、30。

### 阶段五 · 2026.01–2026.10（大二下–大三上）
- **体裁三重转变**：① 日记 = 台账（`Event Log` + `日程` + `时间统计` 脚本）；② 周记 = 9 段固定模板，29 期；③ **散文从随想转为论证**：≥3000 字长文 42 篇（占全阶段 26%），出现 7k–13k 字的独篇（《所以这就是播客？》12,969、《If you wanted me to carry on our dreams》11,641、《婢女骑到了主人头上，还拿错了古典词典》7,597），并出现论文级项目（`判断与反基础主义` 七章大纲 + 英文文献包）、翻译校订、系列小说宇宙（寻找浮士德）。
- **目的**：**生产可引用物**——把自己从"记录者"变成"作者"。
- **连续性**：制度最稳（29 期周记 + 163 天日记），但出现新断档规律（见 §4.4）。

## 4. 合观：日志与非日志的真实关系

### 4.1 引用图（已解析裸名链接）

| 方向 | 条数 | 首次出现 |
|---|---|---|
| `04Journal` → `00写作`/`03灵感` | **169** | 2025-11（周报-31） |
| `00写作` → `04Journal` | **5** | 2026-02 起 |
| `03灵感` → `04Journal` | 1 | 2025-11 |
| `03灵感` → `00写作` | 10 | — |
| `00写作` → `03灵感` | 17 | — |
| `00写作` → `02Area` | 21 | — |
| `00写作` → `01资料` | 16 | — |

**结论一：耦合是单向的、晚生的、且集中在周记。** 169 条中 126 条来自周记、20 条来自 2024 周报、23 条来自日记；发出引用的日志文件仅 46 个，其中 2026-W14（16 条）、W15（12）、W12（11）、W11（10）最密。

**结论二：周记的功能是"作品索引表"。** 引用目标分布：阅读笔记 59 / prose 散文 50 / 文学 19 / 课程笔记 15 / 03灵感 12。被引最多的写作文件：《构成我的九部游戏》7 次、《永远是我的英雄》6 次、《苍白契约》3 次、《我们对权力的奇妙敏感度》3 次、暗黑地牢《赞美三重伟大的赫尔墨斯》3 次。

**结论三：素材不来自日志。** 作品回链的是 `01资料/02梦境`（如 `染色.md → 01资料/02梦境/2026-02-12`）和 `03灵感`，几乎不引日记。**日记是"我自己"，梦境库才是"素材"。**

### 4.4 停更窗与学业节律

- **换算成学期：期末—暑假前是唯一的系统性停更窗。写作节律服从学业节律。**

## 6. 反例与不确定性

1. **"零和"不是严格因果**：5–6 月日记锐减同时是期末周，写作暴增也可能只是"复习时在别的窗口写字"。零和是统计相关，不是机制。
2. **主题表是关键词命中，不是阅读判断**：如"社会"一词同时命中《趣智校园》与《为什么社会不是手机厂商》。占比可比较，绝对值无意义。
3. **2025–2026 合并段（56 篇）是校正后的产物**，其中 24 篇由你口头确认落在"2025 或 2026"，无法再细分。
4. **113 个未定位文件**：主要是 `03灵感/快照` 的即时捕获（58 个，含小红书/知乎导出痕迹）。**缺时间戳的是捕获端，不是写作端**——如果要根治，应该在捕获端（手机剪藏/备忘录）就带上日期。
5. **引用图依赖 Obsidian 链接语法**：601 条链接指向不存在的笔记（未解析），其中可能藏有被删掉的早期作品，链接图的"稀疏"结论需保留余地。
6. **未纳入**：`00写作/Review`（阅读笔记等，但它是被日志引用最多的类别，59 次——**若要补全"写作生态"，Review 是缺口最大的一块**）。
